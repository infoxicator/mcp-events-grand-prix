## JGP–26 car GLBs (realism v2)

Original project geometry generated in Blender 5.2.2 LTS by `scripts/blender/build_car.py`; editable source `scripts/blender/jgp26.blend`. Both LODs and all fictional marks were authored for this demo. No downloaded Ferrari model, trademark decal, video texture or restricted game asset is included. Reference: user-supplied SF–26 explorer video, https://x.com/reach_vb/status/2096271854193271229 (local inspection only). Carbon twill is an original runtime texture; studio environment is Three.js RoomEnvironment. Existing daylight HDR attribution above is unchanged.
